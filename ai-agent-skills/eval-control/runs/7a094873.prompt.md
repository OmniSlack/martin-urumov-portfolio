# A report with measurable values

Rules and quoted requirements: Martin Urumov. Wording of this skill: AI assistant.
The original is in `../../original-bg/izmerimo/SKILL.md`. Tested on 20 September 2026 against a real report on black-hole physics.

---

## What this skill does

It makes every number in a report carry **two independent things**: how sure you are of the claim, and **where the number comes from**. They are not the same, and merging them is the most common error in technical text.

Example from the test — both true at once:

```
🟢 4 ESTABLISHED · shadow diameter of M87* · 42 ± 3 µas · DERIVED
```

The claim is **established** — the Event Horizon Telescope published it, it was peer-reviewed and repeated. The quantity is **derived** — the instrument measures phase and amplitude of radio waves; the ring is a geometric model fitted to sparse data. Without two axes this sentence cannot be written correctly.

---

## Axis 1 · Confidence — how sure you are

| | level | when |
|---|---|---|
| 🟢 | 4 established | facts, data, code or a measurable trace in practice |
| 🟡 | 3 moderate | likely, without direct hard evidence now |
| 🟠 | 2 low | possible, weakly supported |
| 🔴 | 1 hypothesis | an assumption set up for testing |
| 🔵 | 0 synthesis | an image or analogy — **never becomes a scientific fact** |
| ⚪ | — | awaiting audit |
| SC | — | known unknown: you know exactly what you do not know and what is needed |

## Axis 2 · Origin — where the number comes from

| label | meaning |
|---|---|
| **MEASURED** | an instrument gave the number directly, with the instrument's error |
| **DERIVED** | computed from measurements **through an accepted model** — falls if the model falls |
| **DEFINED** | fixed by agreement; its error is **zero by construction** |
| **NEVER OBSERVED** | a theoretical prediction without a single measurement |

⚠️ **DEFINED is the trap.** Since 1983 the speed of light is exactly `299 792 458 m/s` with zero error — because it **defines the metre**. Anyone who says today "we measured c" is in fact measuring **length**.

---

## The row format

```
marker | quantity | value ± error | origin | method | year | source with DOI
```

Every field is mandatory. A missing field is not left empty — the row says why it is missing.

---

## The rules

**1 · 🟢 and 🔵 never in one paragraph.** A paragraph that starts with a measured fact and ends with an image passes the fact's confidence to the image. This is how an analogy becomes "science", and it happens through formatting.

**2 · A chain carries the marker of its weakest link.** 🟢 + 🔴 = 🔴. 🟢 + 🔵 = 🔵.

**3 · The SC section is mandatory, and an empty section is an OMISSION, not a success.** It says what exactly is not known AND which experiment would settle it.

**4 · A "NEVER OBSERVED" section is also mandatory.** It is the most valuable section in the report. In the test it held Hawking radiation, the event horizon itself, and the singularity — three concepts used every day, for which there is not a single measurement.

**5 · A section "derived, but cited as measured".** A list of everything in your own report that people will call measured and is not.

**6 · Last — the strongest argument AGAINST your main conclusion**, put as well as someone who believes it would put it. If it comes out weak, the answer is pleasing you, and the whole report is worth less.

---

## ⚠️ The limit of the error rule — learned at a cost

The rule "**every number carries an error**" applies to **MEASURED and DERIVED** quantities. Imposed without scope, it produces:

```
2019 ± 0        a year
10 ± 0 M☉       a round number in an example
1 ± 0. Section  a section number
```

This is defect **B-10** in [`../../../defect-register/register.json`](../../../defect-register/register.json): *a rule applied outside its scope*. It looks like rigour and is noise. **Say which numbers it applies to.**

No error is written on: years, numbers of sections or items, counts of things, defined constants.
