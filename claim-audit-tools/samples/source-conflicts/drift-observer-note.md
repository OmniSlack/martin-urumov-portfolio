# Sample file for source-conflicts.js

This file stands in for code that uses the name "dual observer" in the second
sense — A = the current state, B = the starting point, the finding is the drift
between them — while the design specification uses the same name for support
against refutation. It is marked DISPUTE-2 so the checker can see that the
disputed name is used knowingly.

Remove the marker above and `node source-conflicts.js` exits 1: the disputed
name would then be used silently.
