# Active-control condition — standardized participant script v0

**Status:** CANDIDATE · version-controlled per PILOT_A_EXECUTION_LOCK_v0.1 §5
**Duration:** 6 minutes, matched to the decentering procedure (same format, audio duration, instruction count, researcher contact).

## Content

Uses the SAME four standardized statements as the decentering condition:

1. "I might answer some items incorrectly."
2. "I want to perform well on this task."
3. "I may feel uncertain about some answers."
4. "This task requires sustained attention."

## Per-statement sequence (directed semantic processing)

1. Read the statement.
2. Identify the main verb.
3. Classify the statement as present-oriented or future-oriented.
4. Count the number of words.
5. Rate how easy the sentence was to understand (0–100).

## Matching requirements (must hold)

Duration · visual format · audio duration · number of instructions · verbal
material · sustained attention · response frequency · researcher contact ·
apparent credibility · expected effort.

## Exclusions (must NOT appear)

Disidentification · distancing language · relaxation · breathing practice ·
distraction · mindfulness · reinterpretation of the statement's meaning.

## Open items (PREREG BLOCKERS)

- Linguistic validation of participant-facing wording.
- Exact audio recording and on-screen timing script (matched to decentering).
